What do I need to play?

A Windows 64-bit computer, keyboard and mouse. This is a downloadable desktop game; it does not run in your browser. Performance varies by hardware. Gamepad and multiplayer are not supported.

What should I know about this release?

This is a free, unsigned prototype. Preferences and personal best are saved locally; campaign progress is not saved. The build passed 67 automated runtime checks, with further human playtesting still welcome. Read the verification report ↗
